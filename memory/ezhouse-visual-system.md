2026-08-10에 상위 성과 썸네일 4종과 영상 2편(scene 분석)을 직접 확인해 정리한 실제 스타일. [[ezhouse-content-formula]]의 카피 공식과 함께 적용.

**Why:** 채널이 이미 일관된 디자인 언어를 갖고 있는데, 내가 처음 만든 광고는 이걸 모르고 임의로 만들었다(빨간 로고 배지 등). 기존 자산과 톤이 어긋나면 브랜드가 흩어진다.

**썸네일 규칙**
- **빨간 테두리 프레임**이 전 썸네일 공통 (가장 강한 시그니처)
  - **두께 = 짧은 변의 3.5%** (2026-08-11 사장님이 3.0%와 4.2% 시안 중 "3번에서 4번 정도"로 확정). 1.9% 이하는 120px로 줄이면 사라진다
  - **가장자리에 밀착**시킬 것. `DrawRectangle` + `PenAlignment::Inset`으로 그리면 바깥에 펜 두께 절반만큼 틈이 남아 지적받았다 → 채움 사각형 4개로 그린다
  - 색상 RGB(226, 26, 26)
- 한글 대형 2~3줄, **1행 흰색 / 강조행 노란색**, 두꺼운 검정 외곽선
- **빨간 알약 배지**로 보조 주장 ("설치기사 없이", "전동공구만")
- **노란 태그 박스**로 카테고리 ("야외간이창고")
- **빨간 곡선 화살표**로 제품 지시
- 치수는 **어두운 빨강 라운드 박스**에 흰 글씨 ("185cm x 120cm / 높이 187cm")
- 최고 성과 구도: **BEFORE / AFTER 좌우 분할 + 중앙 빨간 화살표**, 하단 좌우에 BEFORE·AFTER 라벨(빨간 브러시)
- 사람이 **실제 시공 중인 장면**(지붕 드는 등)도 잘 먹힘
- 썸네일에는 EASY HOUSE 로고 배지를 넣지 않는다

**영상 편집 규칙**
- **0~5초에 완성품을 먼저 보여준다** (결과 선공개가 훅) — 이후 시공 과정
- 오프닝 나레이션에서 즉시 가격+결과 선언: "10만원 자재비로 1평 창고 조립 과정"
- 본문은 **POV·클로즈업 시공 샷** 중심 (흰 작업장갑, 빨강/검정 임팩트 드라이버)
- **분할화면**: 좌=실제 촬영, 우=조립설명서 도면, **빨간 동그라미**로 주의점 강조 ← 시그니처 기법
- **현장음을 BGM 위로 살린다** (드릴 소리, 금속 체결음, 타일 스냅음)
- BGM: 경쾌한 어쿠스틱 기타 또는 업템포 일렉트로닉 팝
- 마무리: 완성품 다각도 → **문 여닫기 시연** → 시공자 만족 표현
- **아웃트로 = 흰 배경 + 검정 집 지붕 아이콘 + 'EASY HOUSE' 검정 볼드 산세리프** (빨간 배지가 아님)
- 엔딩 직전 썸네일 이미지를 한 번 더 노출

**시공자 룩**: 40대 남성, 회색 긴팔, 베이지 카고팬츠, 검정 야구모자, 흰 작업장갑, 공구벨트
