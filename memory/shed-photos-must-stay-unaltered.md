광고·영상 소재를 만들 때 **창고 제품 사진을 AI 생성 모델로 다시 그리면 안 된다.** 사용자가 두 차례 명확히 지적했다: "창고가 이미지가 다 틀렸어", "창고이미지 수정하지마 임의로".

**Why:** Higgsfield의 marketing_studio_image 같은 생성 모델은 참고 이미지를 복사하는 게 아니라 매번 새로 그린다. 그 결과 실제 판매 제품과 다른 창고(경첩문·다른 비율·다른 마감)가 나와 광고로 못 쓴다. 실제 제품은 **미닫이(슬라이딩) 도어**이며 경첩 여닫이문이 아니다.

**How to apply:**
- 제품 컷은 원본 사진에 **로컬 합성**으로 문구만 얹는다 (@napi-rs/canvas + ffmpeg, 크레딧 0)
- 프레임이 안 맞으면 크롭 대신 **outpaint_image**로 배경만 확장한다 — 제품 픽셀은 그대로 보존됨 (2크레딧/장, 검증됨)
- 사람 모델이 필요하면 **창고가 프레임에 없는 문제 장면만** AI로 생성하고, 해결 컷은 실제 사진을 쓴다
- 영상은 프레임을 새로 그리므로 완벽 보존 불가 — Seedance 2.0에 start_image를 주고 "구조를 재설계하지 말라"고 강하게 지시하면 실사용 가능한 수준은 나왔다(검증 완료). 불안하면 정지컷 켄번즈로 대체
- 지금까지 소재로 쓴 제품 컷은 **3x5 모델**(155×77cm, 편경사 지붕, 미닫이 1짝). 라인업 5종 치수는 [[ezhouse-product-lineup]] 참조 — 모델마다 지붕 형태와 문 방식이 다르니 카피에 수치 넣을 때 반드시 확인할 것

**2026-08-11 갱신 — AI 재생성이 조건부로 가능해졌다.** `nano_banana_pro`에 실사진을 `--image`로 넘기고 프롬프트에 **PRODUCT LOCK 블록**을 넣으니 8장 전부 형태가 보존됐다(경첩문·창문·지붕 변형 없음). 락에 명시할 것:

> 박공지붕의 얕은 물매와 은색 용마루 / 촘촘한 세로 골판 다크차콜 벽체 / 도어 베이를 감싸는 은색 트림 기둥 / 전면 박공 상단의 흰 루버 환기구 2개 / 중앙 시임에서 만나는 양문과 작은 검정 손잡이 / 문턱의 낮은 은색 실 / 전체 비율. **재설계 금지, 창문 추가 금지, 미닫이·경첩 코티지문으로 변경 금지, 평지붕·편경사·슁글 지붕으로 변경 금지, 브랜딩/간판/로고 추가 금지.**

그래도 **원본 보존이 기본값**이다. AI 재생성은 [[deliver-both-ab-variants]]에 따라 비교용 B안으로 함께 내고, 최종 채택은 사용자가 정한다.
