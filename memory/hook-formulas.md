2026-08-11 사용자가 공유한 뷰트랩 레터에서 **영상 제작에 필요한 부분만** 추출한 실전 공식. [[ezhouse-content-formula]]와 함께 적용.

**제목·썸네일 구조 6종** (각각 실제로 30만~249만 조회수를 만든 구조)
1. **3단계 기본형**: 강력한 감탄사(시선) → 참을 수 없는 질문(호기심) → 얻을 정보 명시(가치)
2. **쉬운 문제 해결형**: 최소한의 단순한 행동 → 저절로/자동적 결과 → 고질적 문제 해결
3. **특정 목표 달성형**: 도달하고 싶은 목표 상태 → '이런 일'로 가린 미지의 변화 → "무조건/반드시" 단정
4. **직접 검증형**: 고비용 투자·큰 기대 → 치명적 문제 암시(말줄임표) → 직접 뜯어봄/대반전
5. **조건 제시형**: 보편적 만족 결과 → 파격적인 구체 수치·조건 → "직접 확인하세요" 행동 유도
6. **초단기 해결 보장형**: 극단적 난이도 하향("세상에서 가장 쉬운") → 고질적 스트레스 요인 → "N분 종결"

**Why:** 주제를 바꿔도 구조만 유지하면 클릭률이 재현된다(여행 구조를 골프에 이식해 CTR 11.9%·30만 조회수). 자극적 단어 나열이나 유행 추종은 한계가 명확하다.

**How to apply:**
- **반드시 다른 카테고리의 구조를 가져올 것.** 같은 카테고리 썸네일 문구를 쓰면 표절이다.
- 썸네일: 주제 하나만 / 시각 요소 3개 이하 / 텍스트 4단어 이하 / **제목을 그대로 반복하지 말 것**(썸네일은 제목의 감정을 증폭하거나 스토리를 보여줌) / 숫자·비포애프터·실제 결과를 넣을 것
- **도입부 첫 30초가 전부**: 인사·근황·자기소개 금지. "이대로 두면 이런 손해" → "이 영상에서 해결" → "실제 이렇게 바뀐 사례" 순으로 즉시 답한다. 30초를 넘기면 끝까지 볼 확률이 급상승.
- **원고는 결론 → 근거 → 예시** 순. 빌드업을 길게 깔지 말 것. 시청자가 가질 반론("나는 시간이 없는데")을 미리 언급하고 해소한다.
- **아웃트로에서 "마지막으로/끝으로/오늘은 여기까지" 금지** — 시청자가 나갈 채비를 한다. "구독·좋아요" 대신 **"다음은 이 영상을 보세요"**로 다음 영상에 연결.
- **공감은 구체적으로.** "다들 힘드시죠?"는 공감이 아니다. 대상의 상황을 콕 집어야 "내 얘기다"가 나온다.
- 볼 지표는 둘뿐: **클릭률**(제목·썸네일)과 **평균 시청 지속 시간**(도입부). 기준선은 시청 지속 35%·추천 클릭률 4%.
- **업로드 직후 지인에게 공유하지 말 것.** 관심 없는 지인이 클릭 후 바로 이탈하면 알고리즘이 "재미없는 영상"으로 학습해 노출을 멈춘다.
- 숏폼은 초기 도달·유입용, 롱폼은 신뢰와 찐팬 형성용 — 숏폼에만 머물지 말 것.
