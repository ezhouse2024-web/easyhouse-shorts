4. 매 영상은 **새 시나리오 + 새 사진/영상**으로, 기존에 확보한 소재([[ezhouse-install-photos]], [[ezhouse-footage-sources]])를 편집해 만든다.

이득 표현 예시: "찾는 시간이 사라진다" · "예초기가 녹슬지 않는다" · "동선이 짧아져 작업이 빨라진다" · "습기 안 먹고 그대로 보관된다" · "마당이 한눈에 정리된다"

**[2/12] 도입부 원칙**
- 공감 = 핵심 문제를 짚었는가? 사람들이 직면한 문제를 정면으로.
- **기대를 증폭시키는 구조**: "왜 궁금한데? 나한테 도움이 되겠는데?"
- **의문을 증폭시키는 구조**: "그게 뭘까? 궁금한데?"

**[2/13] 도입부를 받쳐주는 장면 8유형** (멘트를 받치면서 극적으로 끄는 장면)
1. 결과가 나오는 장면 (최종 결과물·하이라이트)
2. 일상에서 보기 힘든 신기한 장면
3. 특이하고 엽기적인 장면
4. 공포·긴장이 느껴지는 장면
5. 무언가 진행되는 장면
6. **타겟이 공감되는 장면 (타겟의 문제 상황)** ← 창고 채널에 가장 적합
7. 상황을 반전시켜 웃음 유발하는 장면
8. 예쁜·귀여운·밈 요소

**[2/9] 자료조사 기준 2가지**
1. 타겟의 문제 배경에 **직접적으로** 도움을 주는 영상인가?
2. 경쟁 영상보다 **더 도움을 주는 장면**인가?
- 구성 공식: 결과/권위 + 궁금한 질문 + **얻는 가치 약속** / 권위 있는 사람 + 문제·눈길 + 가치 촉구

**[2/10] 카피 강화 3단계**
- **단어 강화**: "치트키", "비법", "노하우" 같은 강한 단어로 치환
- **수치 강화**: "200% 되돌리는 꿀팁 3가지"처럼 숫자를 박을 것
- **표현 강화**: "초고속으로", "억 소리 나게", "미친 듯이"

**[2/11] 문장 단순화 + 타겟 좁히기**
- 초등학생도 이해하는 문장으로
- 타겟을 콕 집어 부른다: "30대 직장인도 꼭 들으세요", "○○인 분들은 절대 이거 보면 안 됩니다"

**[2/4~8] 3단 구성**
- **도입부**: 문제 제시 + 공감 → 본론 → **결론 = 요약 + 혜택 + 등록/구독 유도**
- 본론 전개 순서: 단계별 / 시간순 / 중요도순 중 택일
- 편집: 자막 + 화면전환은 도입부에 집중

**[2/19~22] 판매 상품 ↔ 용도 ↔ 타겟 확장 맵**
- 제품군: 조립식창고 · 농막 · 간이창고 · 스틸창고 · **타이어보관창고**
- 용도: 농기구, 캠핑용품, 아파트 베란다 접이가구, 어린이용품, 마당 잡기, 교회/종교 도구, 정리창고, 보관창소, 쓰레기 보관소, 분리수거
- 상황: 생활 · 작업 · 업무 · 농사 · 밭일 · 행사 · 정원생활 · 재활농장
- **핵심 질문 프레임**: "왜 사나요? → 어디에, 뭐에 필요한 건가요? → 왜 공간이 필요한가요?" → 집 안이·사무실이·마당이 정리가 안 돼서
- 판매 채널 인식: **쿠팡 < 유튜브**, 저렴한 창고 구매 수요, 전국 대리점
- B2B 확장 구상: 인테리어 업체 B2B, 제휴 영업
